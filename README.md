# proto

Package proto implements ASN.1 wire protocol definitions and codecs for directory services, as defined in [RFC 4511](https://datatracker.ietf.org/doc/html/rfc4511) and [ITU-T rec. X.511](https://www.itu.int/rec/T-REC-X.511).

This package was designed specifically for use by the [Go Directory Project](https://github.com/go-directory).
